do rascunho ao merge

Cada linha de código passa pelos olhos de outra pessoa antes de chegar à main. Role a página: o projeto nasce, se divide em dois ramos e volta a ser um só.

  1. ideia

    Começa numa conversa: que problema vale resolver, e para quem. Anotamos o mínimo que precisa existir para testar a ideia.

  2. protótipo

    Uma primeira versão rápida, só para ver se a ideia para em pé antes de investir semanas nela.

  3. branch

    Cada um puxa a sua parte num branch próprio: web de um lado, mobile e IA do outro, sem pisar no pé de ninguém.

  4. revisão

    Nenhuma linha entra sem o outro ler. É na revisão que mais aprendemos: perguntas, sugestões, um jeito melhor de escrever a mesma coisa.

  5. merge

    As partes se juntam na main, como os dois sobrenomes no nome. O que pode ser aberto vai para o GitHub da organização.

no navegador

o que ele mostra

  • Campo RF F

    A cobertura prevista de cada rede desenhada no piso, com curvas de −50 a −80 dBm.

  • Inspetor clique num nó

    Distância provável com faixa de incerteza, nota de segurança de A a F, fabricante, canal e histórico do sinal.

  • Modo cinema H

    Só o espaço RF, sem painéis, para deixar aberto numa tela.

por dentro

um engine, quatro fontes

A cada 2 s o engine varre o ar, filtra o RSSI de cada rádio com um filtro de Kalman e mantém a identidade das redes entre as varreduras, mesmo quando o sistema esconde o BSSID. Depois estima posições, mede o espectro e a latência e publica o retrato para as duas telas.

como a posição é estimada

Com um único receptor parado, só a distância é observável: ela vem do RSSI pelo modelo log-distância, com a perda típica do ambiente. O azimute não dá para medir com uma antena. Rádios do mesmo AP dividem a direção, redes cujo sinal oscila junto ficam próximas e uma semente fixa mantém o desenho estável. Por isso a interface mostra um anel de distância e um setor provável, não um ponto exato.

plataformas

nativo em cada sistema

  • macOSCoreWLAN, por um helper em Swift compilado no primeiro uso
  • Linuxnmcli, do NetworkManager, e iw para o link
  • Windowsnetsh wlan, com a saída em inglês ou em português
  • Demouma vizinhança sintética, para testar sem hardware

tudo roda na sua máquina

O servidor da visualização 3D escuta só em 127.0.0.1 e recusa origens que não sejam locais. Para a rede saem só o ping até o gateway e até 1.1.1.1, a fonte da interface e, quando você pede, a base de fabricantes da IEEE.

o ano em que a organização nasceu no GitHub

A Dellacarmo nasceu da vontade de criar soluções de tecnologia que impressionem e de aprender fazendo, lado a lado. Felipe vinha dos aplicativos e da IA; Enzo, da web e do back-end. Em vez de cada um seguir no seu canto, juntamos os sobrenomes e os repositórios. Cada projeto é uma chance de estudar algo novo e de revisar o código um do outro antes de ir para a main. Este site é o nosso portfólio e o primeiro projeto aberto da organização: os próximos entram aqui conforme ficarem prontos.

do rascunho ao merge

Cada linha de código passa pelos olhos de outra pessoa antes de chegar à main. É assim que a gente aprende rápido e entrega com cuidado.

ideia

Começa numa conversa: que problema vale resolver, e para quem. Anotamos o mínimo que precisa existir para testar a ideia.

protótipo

Uma primeira versão rápida, só para ver se a ideia para em pé antes de investir semanas nela.

branch

Cada um puxa a sua parte num branch próprio: web de um lado, mobile e IA do outro, sem pisar no pé de ninguém.

revisão

Nenhuma linha entra sem o outro ler. É na revisão que mais aprendemos: perguntas, sugestões, um jeito melhor de escrever a mesma coisa.

merge

As partes se juntam na main, como os dois sobrenomes no nome. O que pode ser aberto vai para o GitHub da organização.
